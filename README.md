# こおりくんのコンビニ（仮）

こおりくんシリーズの コンビニ経営シミュレーション。就活に 失敗した こおりくんが、おにおにバンクからの 借金 100 万円で はじめた コンビニ 1 軒を、1 年で「おかおか (福岡) 1」に する。もとは ユーザーの 企画書 (2026-11-17)。

## ゲームの 流れ
出店地を えらぶ (通学路・遠賀川・小倉駅前) → 毎週「発注と 値段 → シフトと ダンジョン → 営業 → まとめ」を 52 回。月末は おにおにバンクへ 返済 (最初の 1 か月は つけ)。コンビニランキングで 1 位に なったら クリア。

## しくみ
- **値段**: 商品ごとに 10 円 きざみ。地域ごとに「高いと 買わない」ラインが ちがう。客の ひとこと「高っ…」「安っ！」「品切れ？」。安すぎると「安いだけの 店」。
- **消費期限**: 棚の 色で 分かる (緑 → 黄 → 赤)。期限 今日までは 値下げ (値下げハンターが 買う)。期限切れは 廃棄か 子ども食堂 (評判 アップ)。
- **施設** (4 マス): イートイン・たばこ室・駐車場・Wi-Fi・コーヒーマシン・ホットスナック什器・おでん鍋・ATM・冷蔵ケース。施設ごとに 集まる 客層が ちがう。
- **地域**: 客層・好み・特産品が ちがう。好みは 3 週 売ると 分かる。お金を 払えば 移転。
- **スタッフ**: こおりくん・やす・たむ・だけ・こたに・やまもぅ・イシイー・いけきむ・マッスルウエノーブル。接客/品出し/調理/探索。朝・昼・夜の シフト。働かせすぎると やる気が 下がって やめる。やす・たむ・だけ が そろうと 連携ボーナス。
- **ダンジョン** (放置型): ハリーの森・浦の島の海岸どうくつ・月の迷宮。特産品・便利アイテム・幻の 食材。帰ると つかれて いる。
- **限定商品**: 特産品や ダンジョンの 報酬で 特産弁当・きのこ おにぎり・海鮮弁当・幻の 限定弁当。
- **業務連携**: 農場・はたけ (特産品)・ひびき広告 (ひびきまくり)・DJ かっぱ イベント (おかがっぱ)。信頼度で 安く 強く。ライバルに とられる ことも。
- **キャラ**: ふるカワ (まとめの ひとこと)・Mr.SASAKI (月末の 査定)・ともいし (抜き打ち チェック)・シバター (常連)・ゴールド金面犬 (大入り)・KING.ASAHARA (最後の 壁)。
- **エンディング**: 1 位で クリア / 借金を 返した (普通) / 返せない「こおり いきていけない…」。
