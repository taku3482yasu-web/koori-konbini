# こおりくんのコンビニ（仮）

公開: https://taku3482yasu-web.github.io/koori-konbini/ (ゲーム大全 No.08)

こおりくんシリーズの コンビニ経営シミュレーション。就活に 失敗した こおりくんが、おにおにバンクからの 借金 100 万円で はじめた コンビニ 1 軒を、1 年で「おかおか (福岡) 1」に する。もとは ユーザーの 企画書 (2026-11-17)。

## ゲームの 流れ
出店地を えらぶ (通学路・遠賀川・小倉駅前) → 毎週「発注と 値段 → シフトと ダンジョン → 営業 → まとめ」を 52 回。月末は おにおにバンクへ 返済 (最初の 1 か月は つけ)。コンビニランキングで 1 位に なったら クリア。

## しくみ
- **レアスタッフ**: 季節・時期 (お花見・夏・ハロウィン・冬 など) に しか やとえない レアスタッフ 8 人。給料は 高いが 能力が 高く、得意な 商品が よく 売れて、ダンジョンでも 強い。図鑑は 何回 遊んでも のこる。
- **棚と 床**: 店の 床は 12 マス。棚と 施設で わけあう。棚を ふやしたり 撤去したり できる。施設も 撤去できる。スタッフは 解雇できる。
- **エンドレス**: ずっと 経営できる モード (1 位に なっても つづく)。
- **店を 大きく**: お金と 評判が あれば「ふつうの 店」「大きな 店」「おかおか 旗艦店」へ。床と 施設が ふえ、客も ふえる (家賃も 上がる)。
- **商品と 棚**: おにぎり・弁当・サンドイッチ・スイーツ・冷凍食品・カップめん・新聞・雑誌・衣料品・化粧品・文房具・電池・おもちゃ・ギフトカード・中華まん など 28 品。棚は チルド・飲料・冷凍・常温・雑貨・ラックに わかれて いる。
- **難易度**: やさしい・ふつう・むずかしい (ライバルの 強さ・はじめの 手持ち・利息が かわる)。
- **発注と 倉庫**: 商品は 発注しないと とどかない。毎朝 とどいた 商品を 検品して 倉庫へ、品出しで 棚へ。客が 買えるのは 棚の 商品だけ。倉庫が いっぱいだと 受け取れない (倉庫は 広げられる)。
- **持ち場**: スタッフごとに レジ・品出し・検品・調理を きめる。向き 不向きは スタッフで ちがう (★ = いちばん 向いて いる)。
- **値段**: 商品ごとに 10 円 きざみ。地域ごとに「高いと 買わない」ラインが ちがう。客の ひとこと「高っ…」「安っ！」「品切れ？」。安すぎると「安いだけの 店」。
- **仕入れと もうけ** (2026-11-17 ユーザー指定): 発注の 表に「仕入れ」と「1こ の もうけ」(円と 率)。赤字は 赤、率が 低いと 黄色。売り値の ボタンで「定価・ちょい安・ちょい高・もうけ ○% に する」。「ぜんぶ 定価に もどす」。今週の まとめにも 商品ごとの 仕入れ・もうけ。
- **仕入れ値の 変動** (2026-11-17 ユーザー決定): 仕入れ値は 週ごとに 少し 動く (季節・台風・雪・行事)。農場・はたけ・漁協と 組むと 関係する 商品の 仕入れが 下がる (信頼度で もっと)。元の 値から ±25% より 外へは 出ない。売り値は 自動では 変わらない。
- **スマホ** (2026-11-17 ユーザー指定): 幅 640px 以下では 発注の 表を 1 商品 2 段に する。
- **営業の 早送り** (2026-11-17 ユーザー指定): 「1週間 営業する」で 7 日ぶんを 早送りで 見せる (1 日 2 秒くらい)。客が 入って 棚から 取って レジに ならぶ。品切れで 帰る 客・行列で イライラ する 客。雨・雪・行事・ゴールド金面犬・ともいし・シバターも 出る。「スキップ」と「毎週 スキップ」。
- **棚を 調べる** (2026-11-17 ユーザー指定): お店の 絵の 棚を タップすると、棚・倉庫の 数・期限・朝昼夜の 売れ行き (先週の 同じ 曜日と くらべて ↑↓)・品切れ・もうけが 出る。品切れ・期限が 近い 棚には ! の しるし。
- **営業中に 手を 打つ** (2026-11-17 ユーザー決定: 案B): 1 日ずつ・朝昼夜の コマずつ 計算する。止めた ところで 値段を 変える・すぐ 品出し・緊急発注 (あしたの 朝・高め)・シフトの 入れ替え・調理を 増やす・こおりくんの 呼びこみ。品切れ しそうな ときなどは 自動で 止まる (設定で 切れる)。営業の 途中で 閉じても その コマから つづけられる。
- **お店の 見た目** (2026-11-17 ユーザー指定): 床の マスに 通路を はさんで 棚・施設を ならべる。空の 棚は「から」、期限が 近いと 色。
- **音** (2026-11-17 ユーザー指定): 効果音は 合成 (レジの ピッ・品出し・入店の チャイム・お金・ランキング アップ・おにおにの 取り立て)。BGM は `sounds/bgm/<場面>.mp3` が あれば それ、なければ 合成の 曲 (day・night・report・bank・ending)。音量と ミュートは お店の 絵の 右上。
- **はじめての 人への 案内** (2026-11-17 ユーザー指定): 1 週目だけ ふるカワが 順に 案内する (ぜんぶ 目安に → シフト → 営業 スタート)。「❓ 遊び方」から いつでも 見られて、案内も もう一度 見られる。
- **商品の 種類** (2026-11-17 ユーザー指定): 28 品は 商品グループ。おにぎり (梅・昆布・鮭・ツナマヨ・明太子・高菜)・お弁当・サンドイッチ・パン・スイーツ・ドリンク・アイス・カップめん・お菓子・ホットスナック・おでん・中華まんは 中に 種類が ある (期間限定も)。客は グループを 買いに 来て 種類を えらぶ。欲しい 種類が 品切れなら 6 割は 別の 種類を 買う (置いて いない 種類なら 9.5 割)。棚 1 台に 5 種類 まで。発注の 表は グループごとに たためて、「おまかせ」で 先週の 売れ行きで 種類に 分ける。本部 (Mr.SASAKI) の 新商品の おすすめ・SNS の ブーム・商品図鑑 (地域の ページ)。
- **消費期限**: 棚の 色で 分かる (緑 → 黄 → 赤)。期限 今日までは 値下げ (値下げハンターが 買う)。期限切れは 廃棄か 子ども食堂 (評判 アップ)。
- **施設** (4 マス): イートイン・たばこ室・駐車場・Wi-Fi・コーヒーマシン・ホットスナック什器・おでん鍋・ATM・冷蔵ケース。施設ごとに 集まる 客層が ちがう。
- **地域**: 客層・好み・特産品が ちがう。好みは 3 週 売ると 分かる。お金を 払えば 移転。
- **スタッフ**: こおりくん・やす・たむ・だけ・こたに・やまもぅ・イシイー・いけきむ・マッスルウエノーブル。接客/品出し/調理/探索。朝・昼・夜の シフト。働かせすぎると やる気が 下がって やめる。やす・たむ・だけ が そろうと 連携ボーナス。
- **アルバイト**: 求人を 出すと 次の 週に 応募が 来る (その 週の うちに 面接して やとう)。給料は 時給 × 時間で 毎週 はらう (ダンジョン中も)。
- **設備代**: 施設は 買う お金の ほかに 毎週 リース・電気代が かかる。
- **ダンジョン** (放置型): ハリーの森・浦の島の海岸どうくつ・月の迷宮。特産品・便利アイテム・幻の 食材。帰ると つかれて いる。
- **限定商品**: 特産品や ダンジョンの 報酬で 特産弁当・きのこ おにぎり・海鮮弁当・幻の 限定弁当。
- **業務連携**: 農場・はたけ (特産品)・ひびき広告 (ひびきまくり)・DJ かっぱ イベント (おかがっぱ)。信頼度で 安く 強く。ライバルに とられる ことも。
- **キャラ**: ふるカワ (まとめの ひとこと)・Mr.SASAKI (月末の 査定)・ともいし (抜き打ち チェック)・シバター (常連)・ゴールド金面犬 (大入り)・KING.ASAHARA (最後の 壁)。
- **エンディング**: 1 位で クリア / 借金を 返した (普通) / 返せない「こおり いきていけない…」。
